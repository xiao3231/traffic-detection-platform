## 2. 总体说明

本系统为 **B/S 架构的网络流量分析检测平台**，面向毕业设计场景，实现「抓包采集 → 协议解析 → 特征提取 → 机器学习检测 → 样本标注与模型迭代 → 结果展示与审计」的闭环。

- **表示层：** React + Vite 单页应用  
- **业务层：** Flask REST API  
- **数据层：** MongoDB + 本地 PCAP / 模型文件  
- **分析层：** Scapy（抓包与协议解析）+ scikit-learn（随机森林分类）

## 3. 一级功能模块

| 模块 | 职责 |
|------|------|
| **用户与权限管理** | 注册、登录、会话、普通用户与管理员分权 |
| **流量检测服务** | 用户上传 PCAP，流级特征 + 模型推理，文件级安全/危险判定与历史 |
| **抓包协议分析** | 管理员实时/离线抓包、BPF 过滤、包列表与分层解析、会话标注 |
| **机器学习引擎** | 17 维流特征、训练/重训、模型版本、逐流与文件级预测 |
| **数据与会话管理** | MongoDB 持久化会话、检测记录、PCAP 与训练运行档案 |
| **系统管理** | 用户封禁、密码重置、检测统计、运行状态 |
| **前端展示层** | 首页、检测、历史、协议分析等页面 |

## 4. 核心业务流程（论文可配流程图）

1. **检测通道（普通用户）：** 上传 PCAP → 提取流特征 → `model.pkl` 推理 → 任一 malicious 流则文件危险 → 写入 `detection_records` → 历史页统计展示。  
2. **分析通道（管理员）：** 抓包或打开 PCAP → 可选 BPF → 包级协议树 → 特征预览（逐流预测）→ 人工标正常/恶意 → 模型重训 → 更新 `model.pkl`。  
3. **权限通道：** 首注册用户为管理员；后续为普通用户；协议分析、训练、用户管理仅管理员可访问。
